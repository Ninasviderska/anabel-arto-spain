# Anabel Arto Spain

Создаём интернет-магазин женского белья "Anabel Arto" — премиальный бренд свадебного/будуарного белья (Украина), распродажа остатков через испанский шоурум, для клиенток в Испании.

СТЕК: используй бэкенд по умолчанию Lovable (Supabase — Postgres, Auth не нужен для клиентов, только админка), Stripe для онлайн-оплаты.

ЯЗЫК И ЛОКАЛИЗАЦИЯ: основной язык интерфейса и контента — испанский (es-ES), домен будет anabelarto.es. Архитектуру сразу делай i18n-ready (структура роутов/строк текста через словари, например react-i18next или аналог) — в будущем добавим EN, RU, UA версии, но сейчас нужен только испанский контент.

ДИЗАЙН: женственный, элегантный, воздушный стиль — премиальное бельё, не масс-маркет. Кремово-бежевая/пудровая палитра с акцентами (можно тёмно-бордовый/сливовый как акцент), много "воздуха", крупная типографика для заголовков, лёгкая serif-гарнитура допустима для брендовых заголовков. Простая понятная навигация для женской аудитории: каталог по категориям, быстрый переход в карточку, крупные фото, чистая карточка товара с выбором размера/цвета.

СТРУКТУРА КАТАЛОГА (сейчас распродаём один срез ассортимента, но закладываем архитектуру на рост каталога — в будущем добавятся новые категории и поставки из Болгарии/Польши, то есть модель данных должна легко расширяться под мультипоставщика/дропшиппинг):
Категории: Бюстгальтеры (Sujetadores), Трусы (Braguitas), Пеньюары (Picardías), Сорочки (Camisones), Халаты (Batas).
Атрибуты товара: артикул (SKU), тип, цена (€, включая IVA), доступные цвета (со свотчами), доступные размеры (у бюстгальтеров — размер по чашке типа 70B/75C и т.д., у трусов/боди — цифровой размер 36-46, у сорочек/халатов — one size), фото по каждому цвету отдельно, короткое и полное описание на испанском (сделаем позже), остаток на складе по SKU+цвет+размер (появится позже — сейчас можно заложить поля, но временно проставить "в наличии" плейсхолдером/заглушкой, я передам реальные остатки следующим шагом).

ОПЛАТА И ДОСТАВКА: оплата картой через Stripe. Доставка — только по Испании, фиксированная стоимость + бесплатная доставка от порога суммы заказа (точные цифры уточним, пока сделай настраиваемые константы: например 4,95€ доставка, бесплатно от 60€ — это плейсхолдер, заменим).

ЮРИДИЧЕСКОЕ: нужны страницы Aviso Legal, Política de Privacidad, Política de Cookies, Términos y Condiciones, Política de Devoluciones — пока плейсхолдерным текстом, реальные юридические реквизиты (название автономо, NIF, адрес) я передам перед деплоем.

ТЕХНИЧЕСКОЕ SEO (важно, закладывай сразу): чистые человекочитаемые URL на испанском (/es/categoria/producto), автогенерация sitemap.xml и robots.txt, мета-теги title/description на уровне каждой страницы товара и категории (пока плейсхолдеры — реальные испанские SEO-тексты подготовим отдельным шагом), Open Graph теги с фото товара, JSON-LD структурированные данные (Product, Organization, BreadcrumbList), семантическая разметка (h1/h2 иерархия), оптимизация изображений (lazy loading, адаптивные размеры), быстрый Core Web Vitals (минимум JS в критическом пути).

ЭТАП 1 (сейчас): создай базовую структуру проекта — главная страница (хиро-баннер, витрина категорий, преимущества магазина), страница каталога с фильтрами по категории/цвету/размеру, страница карточки товара с выбором цвета и размера и кнопкой "добавить в корзину", корзина, оформление заказа (форма адреса доставки по Испании + переход к оплате Stripe), базовые правовые страницы-заглушки. Наполни каталог 5-7 демо-товарами разных категорий с плейсхолдерными фото и текстами на испанском — это временные данные, реальные 22 SKU с фото и текстами загрузим следующими сообщениями. Название бренда в шапке — "Anabel Arto", логотип пока текстовый, пришлю SVG-логотип отдельным сообщением для замены.
